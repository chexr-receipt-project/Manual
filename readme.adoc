=== AWS Components

==== link:https://aws.amazon.com/lambda/[AWS Lambda]

AWS Lambda will be our code runtime: we do not need to operate servers and and keep then updated. It also auto-scales if needs more CPU and memory, reducing our operational costs in the long term.

link:https://aws.amazon.com/lambda/pricing/?nc1=h_ls[Costs]: it has a free tier that will be sufficient in development time (and even Production at the begining)

==== link:https://aws.amazon.com/rds/[Amazon RDS]

AWS RDS is the relational database service managed by AWS. All data we produce or receive will be stored in this database.

link:https://aws.amazon.com/rds/free/[Cost]: it also have free tier that suits our development needs.

==== link:https://aws.amazon.com/api-gateway/[AWS API Gateway]

API Gateway controls the boundary of the platform: it controls the API documentation, the routes between the internet and internal services, throughput, versions and security. Retailers and Banks will access our system through this service.

link:https://aws.amazon.com/api-gateway/pricing/[Cost]: it has a free tier that suits our development needs.

==== link:https://aws.amazon.com/cognito/[Cognito]

Cognito is the user directory of the platform. Retailers and banks will be stored and have it's access control managed by this service.

link:https://aws.amazon.com/cognito/pricing/[Cost]: it has a free tier that suits our development needs.
